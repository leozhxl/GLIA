# GLIA — Centro Integrado de Desenvolvimento Infantil

Landing page da clínica GLIA, especializada em terapia multidisciplinar infantil (fonoaudiologia, psicologia, neuropsicologia, terapia ABA, nutrição e pediatria).

## Stack

- [Vite](https://vitejs.dev/)
- [React](https://react.dev/) + TypeScript
- [Tailwind CSS](https://tailwindcss.com/)

## Desenvolvimento

```bash
npm install
npm run dev
```
